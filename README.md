# 🌐 portfolioHUB — Portfólio Profissional

> Portfólio digital desenvolvido com HTML5 e CSS3 puro, publicado via GitHub Pages. Documenta experiências, projetos e certificações na área de Infraestrutura, Cloud e Segurança.

🔗 **[Ver portfólio ao vivo](https://apenasrodd.github.io/portfolioHUB)**

---

## 📋 Descrição

Portfólio profissional desenvolvido como parte de atividade acadêmica sobre controle de versão e presença digital. O projeto foi construído do zero com HTML e CSS, sem frameworks, com foco em design limpo, responsivo e de fácil manutenção.

Publicado via **GitHub Pages**, com versionamento completo via Git — demonstrando na prática o fluxo de desenvolvimento, commits organizados e deploy contínuo.

---

## 🛠️ Tecnologias Utilizadas

| Categoria | Ferramenta |
|---|---|
| Markup | HTML5 semântico |
| Estilização | CSS3 (variáveis, Grid, Flexbox, animações) |
| Tipografia | Google Fonts (Syne + DM Sans) |
| Deploy | GitHub Pages |
| Versionamento | Git + GitHub |

## 🚀 Como Executar Localmente

```bash
# Clone o repositório
git clone https://github.com/ApenasRodd/portfolioHUB.git
cd portfolioHUB

# Abra diretamente no navegador
open index.html
# ou simplesmente arraste o arquivo index.html para o browser
```

Não há dependências — tudo é estático.

---

## 🌍 Deploy no GitHub Pages

O portfólio está publicado automaticamente via GitHub Pages a partir da branch `main`.

Para publicar o seu fork:
1. Vá em **Settings → Pages**
2. Em **Source**, selecione `Deploy from a branch`
3. Selecione a branch `main` e a pasta `/ (root)`
4. Clique em **Save**
5. Acesse em `https://seu-usuario.github.io/portfolioHUB`
